PHASE 1: Classical Machine Learning (Core)

Time: 8-10 weeks

1.1 Supervised Learning - Regression

Algorithm What to Learn Code Task
Linear Regression Model: y = Xθ + ε. MSE loss. Normal Equation: θ = (XᵀX)⁻¹Xᵀy. Gradient Descent derivation. Implement from scratch in NumPy. Test on Boston Housing.
Polynomial Regression Adding polynomial features. Overfitting with high-degree polynomials. Implement PolynomialFeatures. Plot degree vs error.
Ridge & Lasso Regression L2 vs L1 regularization. Why L1 creates sparsity. Bias-Variance tradeoff. Add L1/L2 to your LR code. Compare weight shrinkage.
Evaluation MSE, MAE, RMSE, R² score. Compute all metrics manually.

1.2 Supervised Learning - Classification

Algorithm What to Learn Code Task
Logistic Regression Sigmoid function. Cross-Entropy loss derivation from MLE. Gradient descent update. Implement from scratch. Test on Breast Cancer dataset.
Multi-class Logistic One-vs-Rest (OvR). Softmax function. Multinomial Cross-Entropy. Implement Softmax. Test on Iris (3 classes).
Evaluation Confusion Matrix, Precision, Recall, F1, ROC-AUC. Compute all metrics manually. Plot ROC curve.
Class Imbalance SMOTE, class weights, appropriate metrics (F1, PR-AUC). Apply SMOTE. Compare F1 scores.

1.3 Supervised Learning - Non-Linear

Algorithm What to Learn Code Task
K-Nearest Neighbors (KNN) Distance metrics (Euclidean, Manhattan). Choice of k. Curse of Dimensionality. Implement brute-force KNN from scratch.
Naïve Bayes Bayes theorem. Conditional independence. Gaussian, Bernoulli, Multinomial variants. Implement Gaussian NB from scratch. Test on text/spam data.
Support Vector Machines (SVM) Max-margin hyperplane. Support vectors. Hinge loss. Soft-margin (C). Kernel trick (RBF, Polynomial). Tune SVM on sklearn. Visualize support vectors.

1.4 Decision Trees & Ensembles

Algorithm What to Learn Code Task
Decision Trees Splitting criteria: Gini, Entropy, Information Gain. Pruning (Pre/Post). Implement DT from scratch (recursive splitting).
Random Forest Bagging (bootstrap sampling). Feature subsampling. Out-of-Bag (OOB) score. Implement RF from scratch (simplified) or use sklearn.
Gradient Boosting Sequential learning. Fitting to residuals. XGBoost, LightGBM, CatBoost. Train XGBoost on a Kaggle dataset. Tune: n_estimators, eta, max_depth, subsample.
Stacking & Voting Base models → Meta-model. Hard vs Soft voting. Implement VotingClassifier or StackingClassifier.

1.5 Unsupervised Learning

Algorithm What to Learn Code Task
K-Means Distance to centroids. WCSS. Elbow method. K-Means++ initialization. Implement K-Means from scratch.
Hierarchical Clustering Agglomerative (bottom-up). Linkage: Single, Complete, Average, Ward. Dendrogram. Plot dendrogram using scipy.
DBSCAN Density-based. Epsilon (ε), MinPts. Core, Border, Noise points. Use sklearn. Compare to K-Means on concentric circles.
PCA (Principal Component Analysis) Covariance → Eigenvectors → Projection. Explained Variance. Dimensionality reduction. Implement PCA from scratch using SVD. Visualize 2D projection.
Gaussian Mixture Models (GMM) Soft clustering. Expectation-Maximization (E-step, M-step). Use sklearn.mixture.GaussianMixture.

PHASE 2: Deep Learning

Time: 8-10 weeks

2.1 Neural Network Fundamentals

Topic Sub-Topics Code Task
Perceptron Linear neuron. Step activation. XOR problem. Implement Perceptron.
MLP (Multi-Layer Perceptron) Forward pass: Z = WX + b, Activation (ReLU, Sigmoid, Tanh). Implement forward pass for 2-layer net.
Backpropagation Chain rule. Derive gradients: dW², db², dW¹, db¹. Derive on paper. Implement backward pass in NumPy.
Training Loop Forward + Backward + Weight update. Batch vs Mini-Batch. Train your NumPy net on MNIST (binary). Plot loss.
Weight Initialization Random, Xavier/Glorot, He initialization. Vanishing/Exploding gradients. Compare convergence with different inits.
Regularization Dropout, Batch Normalization, L2 regularization. Add Dropout & BN to your MNIST net.

2.2 Convolutional Neural Networks (CNNs)

Topic Sub-Topics Code Task
Convolution Operation Kernel/Filter. Stride, Padding. Channels (RGB). Implement 2D convolution manually.
Pooling MaxPooling, AveragePooling. Downsampling. Implement MaxPool2d from scratch.
CNN Architecture Conv2d → BN → ReLU → Pool → Flatten → Dense. Build CNN for MNIST/CIFAR-10 in PyTorch.
Transfer Learning Fine-tuning vs Feature Extraction. Pretrained: ResNet, EfficientNet. Load pretrained ResNet. Fine-tune on custom dataset (Cat/Dog).
Visualization Feature maps. Grad-CAM (Gradient-weighted Class Activation Mapping). Apply Grad-CAM on ResNet.

2.3 Sequence Models (RNN/LSTM)

Topic Sub-Topics Code Task
RNN Theory Hidden state: hₜ = tanh(Wₕₕ hₜ₋₁ + Wₓₕ xₜ). Vanishing/Exploding gradients. Visualize RNN unrolling.
RNN - Code Implement RNN cell. Predict sine wave sequence.
LSTM Theory Forget Gate, Input Gate, Output Gate, Cell State. Equations for each gate. Derive LSTM equations.
LSTM - Code Implement LSTM using PyTorch. Bidirectional LSTM. Train LSTM on time series (stock/weather).
GRU Gated Recurrent Unit. Fewer gates. Compare LSTM vs GRU on same dataset.

2.4 Attention & Transformers

Topic Sub-Topics Code Task
Self-Attention Q, K, V. Scaled Dot-Product: softmax(QKᵀ/√dₖ)V. Implement Self-Attention from scratch in NumPy.
Multi-Head Attention Project Q, K, V into h subspaces. Concatenate. Code Multi-Head Attention in PyTorch.
Positional Encoding Sinusoidal encodings. Why order matters. Implement positional encoding.
Transformer Encoder Multi-Head Attention → Add & Norm → FFN → Add & Norm. Build Transformer Encoder layer.
Transformer Decoder Masked Self-Attention. Cross-Attention. Build Decoder layer.
Mini-Transformer Combine Encoder + Decoder for toy seq2seq task. Train mini-Transformer on sorting/addition.

2.5 Advanced Architectures

Topic Sub-Topics Code Task
Vision Transformers (ViT) Image → Patches → Linear Projection → Position Embedding → Transformer. Load pretrained ViT. Fine-tune on CIFAR-10.
Autoencoders Encoder → Bottleneck → Decoder. Dimensionality reduction. Build a simple autoencoder.
Variational Autoencoders (VAE) Reparameterization trick. Latent space. Build VAE on MNIST. Generate new digits.
GANs Generator vs Discriminator. Min-Max game. Build GAN for MNIST.

PHASE 3: Advanced ML & Optimization

Time: 3-4 weeks

Topic Sub-Topics Code Task
Convex Optimization Convex sets, Convex functions. Global vs Local minima. Determine convexity of loss functions.
Lagrange Multipliers Constrained optimization. KKT Conditions. Derive SVM dual.
Second-Order Optimization Newton's Method: θ_new = θ - H⁻¹∇J. BFGS. Implement Newton's method on simple function.
Information Theory Entropy, KL Divergence, Cross-Entropy, Mutual Information. Compute KL divergence between two Gaussians.
Bayesian ML Prior, Likelihood, Posterior. MAP vs MLE. Implement Bayesian Linear Regression.

PHASE 4: ML System Design & Evaluation

Time: 2-3 weeks

Topic Sub-Topics Task
Cross-Validation K-Fold, Stratified K-Fold, Leave-One-Out. TimeSeriesSplit. Implement K-Fold manually.
Hyperparameter Tuning GridSearchCV, RandomizedSearchCV, Bayesian Optimization. Tune XGBoost using Optuna.
Feature Engineering Handling missing values, outliers. Encoding (One-Hot, Target). Scaling (Standard, MinMax). Feature selection (RFE, SHAP). Build complete preprocessing pipeline.
Model Interpretation Permutation Importance, SHAP values, Partial Dependence Plots. Plot SHAP summary for XGBoost.
ML System Design Design a recommendation system. Design a fraud detection pipeline. Draw architecture diagrams.
